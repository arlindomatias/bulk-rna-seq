Datasets

This project does not fit any model. It collects the differentially expressed genes (DEGs) that each DE project of the repository already reports (results/top_table.csv and results/de_summary.tsv), using the same DEG rule as that project, and puts them in one table: results/all_degs.csv.

DEG table

results/all_degs.csv has one row per gene and dataset where the gene is a DEG: a gene that is a DEG in two datasets has two rows. Columns:

  • SYMBOL, ENTREZID, ENSEMBL: the project's own identifier (Ensembl ID or symbol) plus the others from org.Mm.eg.db / org.Rn.eg.db. Several IDs for one gene are joined with ;. 76 rows have no Entrez ID and 2 have no Ensembl ID.
  • dataset, species, contrast, method, deg_criterion.
  • direction, log2FoldChange (positive = higher in the treated group), stat, stat_type (DESeq2 Wald statistic or limma moderated t), pvalue, padj.
  • key, key_symbol: the cross-dataset gene key (mouse Ensembl ID and its symbol; see below).
  • n_datasets, datasets: in how many and which datasets the gene is a DEG, matched by key.

Effect sizes from DESeq2 and limma are not on the same scale, and the treatments differ (AC-T in GSE295281, doxorubicin alone in the others).

Matching genes across datasets and species

Every gene tested in each dataset (results/gene_map.csv) gets a key: the Ensembl gene ID of the mouse gene. Mouse genes use their own Ensembl ID. GSE178812 has symbols, some of them outdated (Ctgf for Ccn2), so they are mapped through org.Mm.eg.db: first as current symbols, then as aliases, and only when they give exactly one Ensembl ID (an alias whose gene is already in the dataset under its current symbol is dropped). Rat genes use their 1:1 mouse ortholog from Ensembl Compara release 104 (ortholog_one2one), the release of the GSE236404 rat IDs (Ensembl 104, rn6). Genes without a unique key are not matched across datasets. This replaces matching by upper-case symbol, which pairs genes that merely share a name and misses orthologs named differently.

11,670 keys are tested in all 3 datasets. 21 of the 897 DEG rows have no key.

Overlap between datasets

For each pair of datasets, the universe is the genes (keys) tested in both. The p-value is the hypergeometric probability of at least that many shared DEGs if the two DEG lists were independent. The DEG counts in this table only include DEGs whose key was tested in both datasets, so they are lower than the totals above.
